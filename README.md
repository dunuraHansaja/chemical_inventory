## About Laravel

Laravel is a web application framework with expressive, elegant syntax. We believe development must be an enjoyable and creative experience to be truly fulfilling. Laravel takes the pain out of development by easing common tasks used in many web projects, such as:

- [Simple, fast routing engine](https://laravel.com/docs/routing).
- [Powerful dependency injection container](https://laravel.com/docs/container).
- Multiple back-ends for [session](https://laravel.com/docs/session) and [cache](https://laravel.com/docs/cache) storage.
- Expressive, intuitive [database ORM](https://laravel.com/docs/eloquent).
- Database agnostic [schema migrations](https://laravel.com/docs/migrations).
- [Robust background job processing](https://laravel.com/docs/queues).
- [Real-time event broadcasting](https://laravel.com/docs/broadcasting).

Laravel is accessible, powerful, and provides tools required for large, robust applications.

## Chemical Inventory System

INVENTROO is a Laravel inventory application for chemical materials, supplier purchasing, lot/expiry tracking, production consumption, stock adjustments and purchase VAT.

### Start the application

1. Configure `.env` with the database connection and credentials for your environment.
2. Install PHP and frontend dependencies, then run migrations:

   ```powershell
   composer install
   npm install
   php artisan migrate
   npm run build
   php artisan serve
   ```

   Use Node.js 20.19+ or 22.12+ for the Vite toolchain.
3. Open `/setup` to create the first administrator account. Setup is disabled once an account exists. There are no default passwords.

### Inventory workflows

- **Materials:** create and edit catalogue records, category/supplier links, safety notes, reorder levels, stock totals, and CSV import/export.
- **Lots & expiry:** receive opening stock into a named lot, track manufacture/expiry dates, and review expiring or depleted batches.
- **Purchases:** save a draft supplier order, edit or remove the draft, and receive it once to create stock lots and ledger entries. VAT is saved per purchase using the Settings default unless overridden on the order.
- **Production:** record raw material inputs and finished material outputs in one transaction. Inputs are consumed from unexpired lots in first-expiry-first-out order. Insufficient stock rejects and rolls back the entire run; completed runs are immutable.
- **Stock movements:** receipts, production and documented adjustments append signed, read-only ledger entries. Stock cannot be adjusted below zero.
- **Suppliers and categories:** maintain catalogue records; records in use cannot be removed. Deactivate them instead.
- **Settings:** configure the display currency and the default VAT percentage for new purchases.

Run the automated feature and unit tests with `php artisan test`.
